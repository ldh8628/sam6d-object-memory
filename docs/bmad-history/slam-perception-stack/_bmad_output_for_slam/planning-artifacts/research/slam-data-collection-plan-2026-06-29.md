# SLAM 확정용 데이터 수집 계획 (ORB-SLAM3 / ORB-SLAM3+IMU / RTAB-Map)

작성일: 2026-06-29 · 목적: SAM-6D 객체 메모리(객체 ID + 동일 객체 인식)용 SLAM **3종 중 1종 확정**
센서: Intel RealSense D455 — color 640×480@30, aligned depth, IMU 200Hz (+ camera_info, tf_static)
**모든 bag에 IMU 포함** → 같은 bag을 ORB-RGBD / ORB-IMU / RTAB 셋 다에 적용.

---

## 0. 설계 철학 — 통제변수(OFAT)

> **무작정 X. 기준선 1개 + "한 번에 한 변수"만 바꾼 변형들.**

성능 차이를 바꾼 변수 하나에 **명확히 귀속**시키기 위함. 각 bag은 ① 통제변수 ② 평가차원(D1~D8) ③ 산출지표 ④ 어떤 결정을 짓는가 ⑤ 기대결과를 모두 명시한다.

**평가차원(목적에서 도출):**
| 코드 | 차원 | 객체 메모리와의 연결 | 주 변별 |
|---|---|---|---|
| D1 | 재방문 일관성(loop) | 같은 객체 같은 ID 누적 | RTAB vs ORB |
| D2 | 누적 드리프트 | 객체 절대좌표 정확도 | 공통 |
| D3 | 트래킹 연속성 | pose 끊김 없는 공급 | 공통 |
| D4 | 시점변화 강건성 | 동일 객체 인식 본질 | RTAB vs ORB |
| D5 | 모션 강건성 | 로봇 실주행 | ORB+IMU vs ORB |
| D6 | 시각열화 강건성 | 저텍스처/블러/가림/조명 | ORB+IMU vs ORB |
| D7 | 재배치 복구 | 일시 가림 후 재발견 | 공통 |
| D8 | 장거리 일반화 | 큰 작업공간 | 공통 |

## 1. 공통 배치 (LAYOUT) — 3종 재사용

### LAYOUT-1 "Figure-8 섬" (재방문/모션/시각열화 시리즈 기본)
- 테이블 2개를 방 중앙에 **2.0~2.5m 간격** 분리(8자 교차로 확보), 각 테이블 둘레 **보행반경 ≥1.0m**
- 객체 5~6개: 테이블당 3개, **가장자리 바깥쪽·서로 다른 방향(북/동/남/서)** → 한 바퀴엔 일부만, 반대편 돌 때 나머지 = 시점변화 강제
- 객체 간 ≥30cm, 보행로에서 0.5~2.5m(depth 유효)
```
   ┌──────────────── 방(~5×5m) ───────────────┐
   │   ┌────────┐              ┌────────┐      │
   │   │TableA  │              │TableB  │      │
   │   │O1 O2 O3│              │O4 O5 O6│      │
   │   └────────┘              └────────┘      │
   │      ╲ loop1 ╱╲          ╱╲ loop2 ╱       │
   │       ╲─────╱  ╲  X(교차) ╱  ╲────╱        │
   │  ●start         ╲───────╱                 │
   └────────────────────────────────────────────┘
   8자: start→A 시계1바퀴→X→B 반시계1바퀴→X→반복
```

### LAYOUT-2 "복도 왕복" (장거리/드리프트 시리즈)
- 두 테이블을 **복도/긴 공간 양 끝(15~25m 간격)** 에 배치, 각 끝에 객체 3개씩
- 경로: 한쪽 끝 객체 관측 → 직선 이동 → 반대 끝 객체 관측 → 복귀(왕복)

### LAYOUT-3 "단일 섬 둘레 루프" (단순 기준선/재현 검증)
- 두 테이블을 **맞붙여 중앙 1개 섬**, 객체 6개를 둘레에, 사람은 둘레를 원형 순환

### pseudo-GT (AprilTag 미사용)
- **start(●)=방 원점(0,0)** 바닥 테이프; 모든 bag은 **start로 정밀 복귀**하여 종료 → 시작-끝 오차 = 순수 드리프트
- **객체 바닥중심 (x,y) + 테이블 4모서리** 줄자 측정표 1회 작성 → SAM-6D 객체좌표 정답 / 맵 정합 검증

## 3. 수집 순서 & 분량
1. 줄자 GT 측정표 작성(1회) → B01 → B02 → B04 → B05 → B03 (Tier1 우선)
2. 여유 시 Tier2 (B06~B10), 그다음 Tier3
- 각 bag 2~4분, start 정지 2초로 시작·정밀 복귀로 종료
- **반복 신뢰성**: 핵심 bag(B01,B02,B04)은 **각 2회** 촬영(분산 확인)

## 4. 분석 매핑 (수집 후 자동 처리)
| 지표 | 스크립트 |
|---|---|

## 5. 확정 규칙 (campaign 종료 후)
- **D1·D4 (B01~B03,B08)**: RTAB 루프≫ORB & 역방향/재진입도 폐합 → **RTAB 확정**
- **D5·D6 (B04~B06,B09~B11)**: 거친/열화 조건에서도 IMU가 RGB-D 못 이김 → **ORB+IMU 제외**; 이기면 "거친 배포 시 IMU" 조건부
- **D2·D8 (B07)**: 장거리 드리프트 최소 SLAM 가산점
- **최종**: D1·D4가 객체 메모리에 결정적 → 그 우위 SLAM 채택, D5·D6는 IMU 채택 여부만 결정
